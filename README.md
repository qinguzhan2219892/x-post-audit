# X 发帖诊断

用于 X/Twitter 中文帖子和长文的发布前检查。

输入稿件，获得有原文依据的评分、最多三个优先修改项、完整改稿及同标准复评。

## 使用

将本仓库放到 Codex 的 `~/.codex/skills/x-post-audit` 目录，然后在对话中输入：

```text
用 $x-post-audit 检测下面这篇文章，给出评分、整改意见和改稿：

粘贴正文
```

也可以提供文件或文章链接；链接内容无法完整读取时，需要补充正文。

## 评分维度

| 维度 | 满分 |
|---|---:|
| 读者价值 | 25 |
| 信息增量 | 20 |
| 可信度 | 20 |
| 开头清晰度 | 15 |
| 可读性 | 10 |
| 行动与交流价值 | 10 |

评分是人工编辑量表下的内容诊断，不是平台内部权重，不预测曝光或涨粉。修改保留事实和作者口吻，不编造数据；不会自动发布。

## 文件

- `SKILL.md`：诊断与整改规则。
- `agents/openai.yaml`：技能显示名称和调用提示。
